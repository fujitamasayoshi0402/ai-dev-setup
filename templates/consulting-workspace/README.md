# 相談ワークスペース

AI に相談しながら、**知見を貯めて成果物を作る**ためのフォルダです。SEO・ブランディング・企画・デザインなど、開発以外の仕事に使えます。

## 最初にやること
1. `10_context/profile.md` と `10_context/brand.md` の「〇〇」を埋めます（AI に「10_context を一緒に埋めて」と頼めば、質問しながら埋めてくれます）
2. Orca でこのフォルダを登録し、エージェントを起動します

## 使い方
| やりたいこと | AI への頼み方 |
|---|---|
| 相談を始める | 「〇〇について相談したい」 |
| 成果物を作る | 「この案件の記事構成案を作って」「企画書にまとめて」 |
| 知見を貯める | 「この案件で学んだことを知見にまとめて」 |
| 過去の知見を探す | 「SEO について、これまでに貯めた知見を教えて」 |

## 成果物の型（`90_templates/`）
| 型 | 用途 |
|---|---|
| `proposal.md` | 企画書・提案書 |
| `article-outline.md` | 記事の構成案（SEO 記事など） |
| `seo-report.md` | SEO の現状分析と改善案 |
| `brand-guide.md` | ブランドガイド |
| `design-brief.md` | デザインの依頼書 |
| `image-prompt.md` | 画像生成 AI への指示文 |

型が足りなければ、AI に「〇〇の型を 90_templates に追加して」と頼めます。

Obsidian で「フォルダを保管庫として開く」から開くと、メモとして読み書きもできます。
