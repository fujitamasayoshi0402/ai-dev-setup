# 成果物を作る

## 手順

1. **案件と成果物の種類を確認する**
   - どの案件か（`30_projects/` のどのフォルダか）。案件がなければ、先にスキル `consult` で作る
   - 何を作るか。`90_templates/` に合う型があればそれを使う。なければ一般的な構成を提案し、了承を得てから作る（よく使いそうなら、型として `90_templates/` に追加することを提案する）
2. **材料を読む**
   - 案件の `brief.md` と `notes.md`
   - `brief.md` の「資料」に書かれたファイル（案件の `materials/` など）。指定キーワード・数値・NG 事項などを読み落とさない
   - `10_context/brand.md`（トーン・言葉づかい・見た目）
   - 関係する `20_knowledge/` の知見
3. **作る**
   - 保存先: `30_projects/<案件>/outputs/YYYY-MM-DD-種類-タイトル.md`
   - 型の見出しの順番を守る。埋められない項目は空欄にせず「要確認: 〇〇」と書く
   - 事実・数字には出典を書く。推測で書かない
   - 画像そのものは作らない。必要なら `image-prompt.md` の型で画像生成 AI 向けの指示文を作る。図やアイコンは SVG で作ってよい
4. **確認してもらう**。要点を3行で伝え、直したいところを聞く。修正は同じファイルに反映する
5. **記録する**。完成したら `notes.md` に「YYYY-MM-DD 〇〇を作成（outputs/ファイル名）」と追記し、コミットする
6. **知見の提案**。作る過程でわかったこと（うまくいった型の使い方など）があれば、スキル `harvest-knowledge` を提案する
