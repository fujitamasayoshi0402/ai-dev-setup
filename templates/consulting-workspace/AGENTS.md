# AGENTS.md

この「相談ワークスペース」で作業する AI エージェント向けのルールです。
相談（SEO・ブランディング・企画・デザインなど）を受けて、**知見を貯めながら成果物を作る**ための場所です。

## フォルダの役割
- `00_inbox/` … 相談したいこと・資料・メモをとりあえず置く場所
- `10_context/` … 毎回読む前提情報（`profile.md`: 自分・会社・お客さん、`brand.md`: トーン＆マナー）
- `20_knowledge/` … 相談で得た知見。テーマ別のフォルダ（例: `seo/`、`branding/`、`design/`）に貯める
- `30_projects/` … 案件ごとのフォルダ（`YYYY-MM-案件名/`）。中に `brief.md`・`notes.md`・`outputs/`
- `90_templates/` … 成果物とメモの型。中身は書き換えない

## 基本の流れ
1. **相談を始める** → スキル `consult`
2. **成果物を作る** → スキル `make-deliverable`
3. **知見を貯める** → スキル `harvest-knowledge`（案件の区切りや完了時）

## いつも守ること
- 作業を始める前に `10_context/` を読む。`〇〇` のままの項目があれば、埋めるか利用者に聞く
- 関連しそうな `20_knowledge/` を探して読み、使った知見はどれか利用者に伝える
- 文章のトーンは `10_context/brand.md` に従う
- 事実や数字には出典を書く。確認できないことは「要確認」と書く
- 利用者はプログラミング経験がない場合がある。専門用語には短い説明を添える
- 画像そのものは作らない。必要なら画像生成 AI 向けの指示文（`90_templates/image-prompt.md`）を作る。図やアイコンは SVG で作ってよい
- パスワード・API キー・お客さんの個人情報は、知見（`20_knowledge/`）に書かない
- 既存のファイルを消したり大きく書き換えたりする前に、利用者に確認する

## スキル
- スキルは `.agents/skills/<名前>/` と `.claude/skills/<名前>/` の両方に同じ内容で置く
- 外部から取り込んだスキルは `.agents/skills/SOURCES.md` に記録する

## Git
- ひと区切りごとにコミットする（例: 「案件 〇〇: 構成案を作成」）
- GitHub を使っていない場合: `main` にそのままコミットしてよい
- GitHub を使っている場合: 非公開（Private）リポジトリにする。お客さんの情報を含むため、公開しない
