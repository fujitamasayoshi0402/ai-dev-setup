# My Vault

AI と一緒に使う Obsidian の保管庫です。フォルダの役割は `AGENTS.md` を見てください。

## 最初にやること（Obsidian の設定）
1. Obsidian で「フォルダを保管庫として開く」からこのフォルダを開く
2. 設定 → コアプラグイン →「テンプレート」をオン → テンプレートフォルダの場所を `90_templates` にする
3. 設定 → コアプラグイン →「デイリーノート」をオン → 新規ファイルの場所を `10_daily`、テンプレートを `90_templates/daily` にする
4. 設定 → ファイルとリンク →「新規ノートの作成場所」を `00_inbox` にする
