# できあがったものを作る

## 手順

1. **どの仕事の、何を作るかを確認する**
   - どの仕事か（`work/` のどのフォルダか）。まだ仕事のフォルダがなければ、先にスキル `start-work` で作る
   - 何を作るか。`templates/` に合うひな形があればそれを使う。なければ一般的な構成を提案し、了承を得てから作る（よく使いそうなら、ひな形として `templates/` に追加することを提案する）
2. **材料を読む**
   - 仕事の `request.md` と `notes.md`
   - `request.md` の「資料」に書かれたファイル（`materials/` など）。指定された言葉・数字・やってはいけないことを読み落とさない
   - `about/brand.md`（文章の雰囲気・使わない言葉・色）
   - 関係する `knowhow/` のノウハウ
3. **作る**
   - 保存先: `work/<仕事>/outputs/YYYY-MM-DD-種類-タイトル.md`
   - ひな形の見出しの順番を守る。埋められない項目は空欄にせず「要確認: 〇〇」と書く
   - 事実・数字には出典を書く。推測で書かない
   - 画像そのものは作らない。必要なら `image-prompt.md` の形で、画像生成 AI への指示文を作る。図やアイコンは SVG で作ってよい
4. **見てもらう**。要点を3行で伝え、保存した場所（Finder やエクスプローラーでの開き方も）を教える。直したいところを聞き、同じファイルに反映する
5. **記録する**。完成したら `notes.md` に「YYYY-MM-DD 〇〇を作成（outputs/ファイル名）」と書き足し、コミット（保存）する
6. **ノウハウの提案**。作る中でわかったこと（うまくいった書き方など）があれば、スキル `save-knowhow` を提案する
