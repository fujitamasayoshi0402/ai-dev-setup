# AI 仕事部屋

AI に仕事を手伝ってもらうための部屋です。企画・文章・調べもの・SEO・SNS・デザインの準備など、いろいろな仕事に使えます。

使うほど、あなたの仕事のノウハウが `knowhow/` に貯まり、AI がそれを読んで、次の仕事をもっと上手に手伝ってくれるようになります。

## 最初にやること（5分）
1. Orca でこのフォルダを登録し、エージェントを起動します（作業フォルダ = worktree は作らず、このフォルダそのもので起動します）
2. エージェントに次のように頼んで、`about/` を一緒に埋めます

```
about の profile.md と brand.md を、質問しながら一緒に埋めて
```

## 使い方
話しかけるだけです。フォルダやファイルは AI が作ります。

| やりたいこと | AI への頼み方の例 |
|---|---|
| 相談を始める | 「ブログの記事について相談したい」 |
| できあがったものを作る | 「この内容で企画書を作って」「SNS 投稿を3つ考えて」 |
| ノウハウを残す | 「今回わかったことをノウハウに残して」 |
| ノウハウを使う | 「ブログについて、これまでのノウハウを教えて」 |
| 続きをする | 「先週のブログ記事の続きをしたい」 |

## フォルダの中身
| フォルダ | 何が入るか |
|---|---|
| `about/` | あなた・お店・会社のこと、文章の雰囲気 |
| `inbox/` | 受け取り箱（相談したいこと・資料をとりあえず置く） |
| `work/` | 仕事ごとのフォルダ（AI が作る） |
| `knowhow/` | 貯まっていくノウハウ |
| `templates/` | できあがったもののひな形 |

## ひな形（`templates/`）
| ひな形 | 使う場面 |
|---|---|
| `proposal.md` | 企画書・提案書 |
| `article-outline.md` | ブログ・SEO 記事の構成 |
| `sns-post.md` | SNS の投稿 |
| `email.md` | メール・お知らせ・案内文 |
| `minutes.md` | 打ち合わせのメモ（議事録） |
| `research.md` | 調べもののまとめ |
| `seo-report.md` | サイトの検索対策（SEO）の分析と改善案 |
| `brand-guide.md` | ブランドのルールブック |
| `design-brief.md` | デザインの依頼書 |
| `image-prompt.md` | 画像生成 AI への指示文 |

足りないひな形は「〇〇のひな形を templates に追加して」と頼めば増やせます。

このフォルダは Obsidian（メモアプリ）で「フォルダを保管庫として開く」から開くこともできます。
