## 構成
- `src/` … アプリのコード（コードを書き始めるときに作る）

## ルール
- 回答とコミットメッセージは日本語
- コミット前に lint と test を通す
- 新しいライブラリを追加する前に確認する
- `.env` の中身を読んだり、出力したりしない

## スキル
- スキルは `.agents/skills/<名前>/` と `.claude/skills/<名前>/` の両方に同じ内容で置く
- 外部から取り込んだスキルは `.agents/skills/SOURCES.md` に記録する
- 取り込むときは中身を確認し、利用者の了承を得てから入れる

## Git
- 新しい作業は `feature/〜` `fix/〜` のブランチ（Orca では worktree）で行う
- GitHub を使っていない場合: 作業が終わったら、利用者の確認を取ってから `main` にマージする
- GitHub を使っている場合: `main` に直接コミットせず、PR を出す
- 1つの変更ごとに小さくコミットする
