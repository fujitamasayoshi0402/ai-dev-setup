# AI への頼み方のコツ

AI エージェントは、**頼み方しだいで結果が大きく変わります**。このページでは、仕事の種類に関係なく使える頼み方のコツをまとめます。具体的な頼み方の例は [使い方レシピ集](06-recipes.md) も参考にしてください。

## 1. 頼み方の基本の型

次の4つを入れると、AI が迷わずに動けます。全部そろっていなくても大丈夫です。

```
【目的】何のためにやるか
【条件】守ってほしいこと
【ゴール】何ができたら終わりか
【やらないこと】今回は手を出さないこと
```

**例（ブログ記事）**

```
【目的】お店のブログで、新メニューのパンを知ってもらいたい
【条件】やさしい雰囲気で。800文字くらい。値段は 1 個 280 円
【ゴール】タイトル案3つと、本文の下書きができている
【やらないこと】写真は自分で用意するので、画像は作らなくていい
```

**例（Web サイト）**

```
【目的】お店の紹介サイトに、メニューのページを追加したい
【条件】スマホで見やすく。今のトップページと同じ色にする
【ゴール】メニューのページが表示され、トップページからリンクで行ける
【やらないこと】ネット注文の機能は作らない
```

## 2. 迷ったら、AI に質問してもらう

何を書けばいいかわからないときは、AI に聞いてもらうのがいちばん簡単です。

```
〇〇をしたい。何を決めればいいか、1つずつ質問して
```

## 3. 大きな仕事は「まず計画」

いきなり作らせず、まず計画を出してもらい、確認してから進めます（計画モードがあるエージェントも多いです）。

```
まず進め方の計画だけ出して。作るのは、私が OK と言ってからにして
```

## 4. 直してほしいときは「どこを・どう・なぜ」

| ❌ あいまい | ✅ 具体的 |
|---|---|
| もっといい感じにして | タイトルを、もう少しやわらかい言葉にして。読者は子育て中の人だから |
| 違う | 2つ目の段落の値段がまちがっている。280 円が正しい |
| デザインを変えて | 文字を今の 1.5 倍の大きさにして。スマホだと小さくて読みにくいから |

「なぜ」を添えると、AI が同じような箇所もまとめて直してくれます。

## 5. 結果は必ず自分で確認する

AI はまちがえることがあります。特に次の点は、外に出す前に自分で確認します。

- **事実や数字**（日付・値段・統計など）。「出典（どこで調べたか）も教えて」と頼むと確認しやすくなります
- **固有名詞**（人の名前・お店の名前・商品名）
- **見た目**（Web サイトなら、スマホとパソコンの両方で開いてみる）

わからないところは、遠慮なく聞いてかまいません。

```
今やったことを、専門用語を使わずに3行で説明して
```

## 6. 話題が変わったら、新しい会話にする

1つの会話が長くなると、古い話に引っぱられて精度が落ちます。別の仕事を始めるときは、新しい会話（新しいタブ）にします。続きをしたいときは「〇〇の続きをしたい」と頼めば、AI が記録を読んで思い出してくれます（[AI 仕事部屋](05-ai-workroom.md) では、記録が自動で残ります）。

## 7. こまめに保存する（取り消せるように）

AI に作業を任せるときは、**こまめに保存（コミット）**しておくと、うまくいかなかったときに元に戻せます。Git の操作は AI に頼めば大丈夫です。

| タイミング | 頼み方の例 |
|---|---|
| ひと区切りついたとき | 「ここまでを保存（コミット）して」 |
| おかしくなったとき | 「さっき保存した状態に戻して」 |
| 何を変えたか知りたいとき | 「前に保存してから、何を変えたか教えて」 |

## 8. AI に任せてはいけないこと

- **送信・購入・予約・公開**などの、取り消せないこと。AI には下書きまでを頼み、最後のボタンは自分で押します
- **パスワードや API キーをチャットに貼ること**。必要なときは `.env` というファイルに置き、AI には「`.env` の〇〇を使って」と場所だけ伝えます
- **社外秘の情報を、許可されていないサービスに渡すこと**（仕事で使う場合は会社のルールを確認します）

## 9. 毎回言っていることは、ルールにする

同じお願いを何度もしているなら、`AGENTS.md`（AI が毎回読む指示書）に書いておきます。書き方は [AGENTS.md の書き方](08-agents-md.md) を参照してください。

```
「専門用語は使わないで」と毎回言っているので、AGENTS.md のルールに書き足して
```

## Tips 集

| Tips | 内容 |
|---|---|
| 例を見せる | 「こんな感じで」と、好きな文章や過去の資料を見せると、雰囲気が伝わりやすい |
| 選択肢を出してもらう | 「3案出して。それぞれのよい点・悪い点も」と頼むと、比べて選べる |
| 役割を伝える | 「プロの編集者として読んで、直すところを教えて」のように役割を伝えると、見方が変わる |
| 別の AI にも見てもらう | 作った AI とは別の AI にチェックしてもらうと、見落としに気づきやすい（[複数のエージェントを使う](12-multi-agent.md)） |
| わからないことは何でも聞く | エラー文・専門用語・手順など、「わかりやすく説明して」と聞いてよい |
