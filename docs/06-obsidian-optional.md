# Obsidian（オプション）

> このページは任意です。AI 駆動開発自体は Obsidian なしでも問題なく行えます。

[Obsidian](https://obsidian.md/) は Markdown ファイルでメモを管理するアプリです。データがただの `.md` ファイルなので、**AI エージェントがそのまま読み書きできる**のが最大の利点です。

## 何に使うと便利か

| 用途 | 例 |
|---|---|
| 調査メモの蓄積 | AI に調べさせた結果を `.md` で保存し、後から検索 |
| 日報・作業ログ | その日 AI に頼んだこと・学んだことを記録 |
| プロンプト集 | よく使う指示文をテンプレート化 |
| 設計メモ | リポジトリの `docs/` を Vault として開き、図やリンクで整理 |

## インストール

### Mac

```zsh
brew install --cask obsidian
```

### Windows

```powershell
winget install --id Obsidian.Obsidian -e
```

## Vault（保管庫）の作り方

おすすめは2パターンです。

### A. 個人ナレッジ用の Vault

```
~/obsidian-vault/
├── 00_inbox/        # とりあえず放り込む
├── 10_daily/        # 日報（YYYY-MM-DD.md）
├── 20_research/     # AI の調査結果
├── 30_prompts/      # プロンプト集
└── CLAUDE.md        # この Vault での AI のルール
```

Vault 内で `claude` を起動すれば、「今週の日報をまとめて」「research の中から○○に関するメモを探して」などが可能になります。

`CLAUDE.md` の例：

```markdown
- メモは日本語で書く
- 新しいメモは 00_inbox/ に作る
- ファイル名は YYYY-MM-DD-タイトル.md
- 既存メモへのリンクは [[ファイル名]] 形式で張る
```

### B. リポジトリの docs をそのまま開く

Obsidian で「フォルダを保管庫として開く」から `my-app/docs/` を選ぶだけ。仕様書を Obsidian で読み書きし、同じファイルを AI も参照できます。

> `.obsidian/` フォルダ（個人設定）は `.gitignore` に入れておきましょう。

## おすすめ設定・プラグイン

| 項目 | 内容 |
|---|---|
| 設定 → ファイルとリンク → 「Wikiリンクを使用」 | オフにすると標準 Markdown リンクになり、GitHub 上でも表示が崩れない |
| コアプラグイン「デイリーノート」 | 日報を1クリックで作成 |
| コアプラグイン「テンプレート」 | 調査メモ・日報の雛形 |
| コミュニティプラグイン「Obsidian Git」 | Vault を GitHub に自動バックアップ |

## 運用のコツ

- **AI の出力は inbox に入れて、人が整理する**。全部 AI 任せにするとノイズが増える
- 調べた結果は「結論 → 根拠 → 参考URL」の順で書かせると後で読みやすい
- 機密情報を含む Vault は公開リポジトリに push しない
