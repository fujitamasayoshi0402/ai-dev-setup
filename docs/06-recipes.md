# 使い方レシピ集

[AI 仕事部屋](05-ai-workroom.md) でよく使う頼み方を、仕事の種類ごとに集めました。**そのままコピーして、「〇〇」を書き換えて使えます**。

- できあがったものは、仕事のフォルダ（`work/…/outputs/`）に保存されます
- 「ひな形」は、部屋の `templates/` にある形です。AI が自動で使います
- うまくいかないときは [AI への頼み方のコツ](07-how-to-ask.md) を見てください

## 企画・アイデア

### 企画書をつくる

```
〇〇（例: 夏休みの親子向けパン作り教室）の企画書を作りたい。相談させて
```

→ 背景・目的・内容・スケジュール・必要なもの・リスクをまとめた企画書（ひな形: `proposal.md`）

### アイデアを出してもらう

```
〇〇（例: 雨の日にお客さんを呼ぶ方法）のアイデアを10個出して。お金がかからない順に並べて
```

→ アイデアの一覧。気に入ったものを「3番を企画書にして」と続けられます

## 文章

### ブログ記事（SEO 記事）を書く

```
「〇〇（例: 食パン 保存方法）」で検索する人に向けたブログ記事を書きたい。まず構成案を作って
```

→ タイトル案・見出しの構成・入れたい情報（ひな形: `article-outline.md`）。構成が決まったら「この構成で本文を書いて」

### SNS の投稿を考える

```
〇〇（例: インスタ）に載せる、〇〇（例: 新メニュー）の紹介を3案考えて。ハッシュタグも
```

→ 投稿文3案とハッシュタグ・添える写真のイメージ（ひな形: `sns-post.md`）

### メール・お知らせを書く

```
〇〇（例: 年末年始の営業日）のお知らせメールを、常連のお客さん向けに書いて。送信はしないで
```

→ 件名案と本文（ひな形: `email.md`）

### 文章を手直ししてもらう

```
次の文章を、〇〇（例: もっとやわらかく・半分の長さに）直して。直したところも教えて
（ここに文章を貼る）
```

→ 直した文章と、どこをどう直したかの説明

## 調べもの

### 調べて、比べてまとめる

```
〇〇（例: ネット予約のサービス）を3つ調べて、料金・使いやすさ・サポートで比べて。参考にしたページも書いて
```

→ 比較表と結論、参考にしたページ（ひな形: `research.md`）

> 調べた内容はまちがえていることがあります。大事な判断の前に、参考にしたページを自分でも確認してください。

## 会議・整理

### 打ち合わせのメモを整理する

```
打ち合わせのメモを inbox に入れた。決まったこと・やること（担当と期限）に整理して
```

→ 決まったこと・やることの表・次回までの確認事項（ひな形: `minutes.md`）

### やることを整理する

```
今週やらないといけないことを書き出すので、優先順位をつけて並べて
（ここに書き出す）
```

→ 優先順位つきの一覧と、その理由

## お店・ブランド

### ブランドのルールブックをつくる

```
お店のブランドガイドを作りたい。about の内容をもとに、足りないところは質問して
```

→ 言葉づかい・色・写真の雰囲気などのルール（ひな形: `brand-guide.md`）。完成したら `about/brand.md` にも反映してもらえます

### キャッチコピーを考える

```
〇〇（例: 天然酵母の食パン）のキャッチコピーを10個考えて。brand.md の雰囲気に合わせて
```

→ キャッチコピーの候補

## Web サイト・検索対策（SEO）

### サイトの検索対策を見直す

```
〇〇（サイトの URL）の検索対策を見直したい。今の状態と、直すとよいところを優先順位つきでまとめて
```

→ 現状・課題・改善案の表（ひな形: `seo-report.md`）

> AI がページを読みに行けない場合は、ページの文章をコピーして貼り付けてください。

## デザイン・画像

### デザインの依頼書をつくる

```
〇〇（例: 店頭に貼るチラシ）のデザインを頼みたい。デザイナーさんに渡す依頼書を作って
```

→ 作るもの・伝えたいこと・入れる要素・雰囲気をまとめた依頼書（ひな形: `design-brief.md`）

### 画像生成 AI への指示文をつくる

```
〇〇（例: 焼きたてのパンが並ぶ朝の店内）の画像を作りたい。画像生成 AI に渡す指示文を、日本語と英語で作って
```

→ 指示文（ひな形: `image-prompt.md`）。AI エージェントは写真やイラストそのものは作らないので、この指示文を画像生成のツールに渡します

### かんたんな図をつくる

```
〇〇（例: 予約から来店までの流れ）を図にして。SVG で保存して
```

→ 図のファイル（SVG）。ブラウザで開いて見られます

## もっと本格的なもの

Web サイトやアプリなど、**プログラムを使うもの**を作りたくなったら、[アプリ・サイトを作る](09-build-projects.md) を参照してください。

## 自分のレシピを増やす

よく頼むことは、**ひな形**や**スキル**にしておくと毎回楽になります。

```
今回の頼み方をよく使うので、ひな形として templates に追加して
```

```
さっきの手順を、次から同じようにできるようにスキルにして
```

スキルについては [スキルの取り込みと共有](11-skills.md) を参照してください。
